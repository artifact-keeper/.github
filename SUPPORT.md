# Getting help with Artifact Keeper

Artifact Keeper is free and open source, maintained by volunteers. Pick the place that fits:

| You want to | Go to |
|---|---|
| Ask a question or get setup help | The `#help` forum on [Discord](https://discord.gg/8T7NW2PeS2) |
| Read how something works | [Documentation](https://artifactkeeper.com/docs/) |
| Propose a feature or discuss an idea | [GitHub Discussions](https://github.com/artifact-keeper/artifact-keeper/discussions) |
| Report a confirmed bug | The issue tracker of the repository it belongs to |
| Report a security vulnerability | Privately, as described in [SECURITY.md](https://github.com/artifact-keeper/artifact-keeper/blob/main/SECURITY.md). Never in Discord or public issues |

Before asking, check the [FAQ](https://artifactkeeper.com/docs/) and existing issues and Discussions. Please include your Artifact Keeper version, how you deployed it, and relevant logs with secrets removed.

Only the latest release is supported. See the [support policy](https://artifactkeeper.com/docs/getting-started/support-policy/).
